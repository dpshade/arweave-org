# Home Page Wireframe Reference

## Design Overview
- **Header**: Top navigation with "Home", "Use", "Build", "Discover", "Get Funded" tabs in top right
- **Main Title**: "Arweave." (large, centered)
- **Subtitle**: "Permanent information storage." (smaller, centered)

## Content Section
- Clean, centered text blocks with good spacing
- Multiple paragraphs explaining Arweave network
- Key points about permanence, decentralization, and ecosystem

## Call to Action
- "Start To Use" button with arrow icon
- Orange/accent color for the button
- Links to the Use page

## Navigation Style
- Top right horizontal tabs, not bottom footer
- "Home" tab should be highlighted/active
- Clean, minimal design with lots of white space
- Focus on typography and readability
